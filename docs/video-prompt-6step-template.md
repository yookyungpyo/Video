# 영상 프롬프트 6단계 템플릿 (주제 → 사운드)

AI 영상 생성(Higgsfield / Seedance 2.5 등)에 넣을 프롬프트를 쓰는 순서와 규칙.
순서는 **주제 → 행동 → 배경 → 스타일 → 카메라 → 사운드**.

## 1. 순서

| # | 항목 | 쓰는 내용 |
|---|------|-----------|
| 1 | 주제 | 무슨 영상인지, 누가(무엇이) 나오는지 |
| 2 | 행동 | 어떻게 움직이는지 (동작을 순서대로) |
| 3 | 배경 | 어디에서, 몇 시쯤, 날씨·빛 |
| 4 | 스타일 | 실사/애니, 색감, 필름 느낌, 무드 |
| 5 | 카메라 | 샷 크기, 카메라 움직임, 렌즈 |
| 6 | 사운드 | 배경음악·효과음·대사·자막 (아래 괄호 규칙) |

## 2. 오디오는 괄호로 지시

| 괄호 | 의미 | 예 |
|------|------|----|
| `( )` | 배경 음악 | `(긴장감 있는 현악)` |
| `< >` | 효과음 | `<삐걱거리는 소리>` |
| `{ }` | 대사 | `{누구세요?}` |
| `[ ]` | 화면 자막 | `[3일 전]` |

예시: `여자가 문을 연다. <삐걱거리는 소리> {누구세요?} (긴장감 있는 현악)`

## 3. 공통 설정 (컷마다 반복하지 않고 한 번만)

| 항목 | 값 |
|------|----|
| 모델 | Seedance 2.5 (Higgsfield) |
| 비율 | 9:16 |
| 길이 | 컷당 10초 (3컷 → 약 30초) |
| 레퍼런스 | 이미지1 = 인물 / 이미지2 = 제품·배경 (있을 때) |
| 오디오 | 네이티브 대사 ON, 한국어 |

> 팁: 레퍼런스 이미지를 넣었으면 인물 외모는 프롬프트에서 한 줄로 짧게.
> 나머지 분량은 행동·빛·카메라에 쓰는 게 일관성에 유리하다.

## 4. 컷 작성 양식 (복사해서 사용)

```
CUT N — <컷 제목>
주제:   
행동:   
배경:   
스타일: 
카메라: 
사운드: ( ) < > { } [ ]
```

## 5. 작성 예시 — 브랜드 마스코트 "출근 전 커피 한 잔" (1컷, 10초)

```
CUT 1 — 오늘의 첫 커피
주제:   레퍼런스 이미지1의 캐릭터(둥근 검정 안경, 곱슬 검은 머리, 파우더블루 블레이저)가 아침 카페에서 커피를 주문한다.
행동:   문을 열고 들어와 카운터 앞에서 메뉴판을 올려다본 뒤, 손가락으로 메뉴 하나를 가리키며 웃는다.
        컵을 받아 한 모금 마시고 카메라를 향해 엄지를 든다.
배경:   햇살이 창으로 비스듬히 들어오는 오전 8시의 작은 동네 카페. 원목 카운터, 김이 오르는 에스프레소 머신.
스타일: 따뜻한 필름 톤, 부드러운 하이라이트, 3D 플러시 캐릭터 질감, 아늑하고 밝은 무드.
카메라: 문 쪽 미디엄 샷에서 시작해 카운터로 천천히 트래킹, 마지막 1초는 얼굴 클로즈업으로 푸시인.
사운드: <문 종소리 딸랑> {아메리카노 한 잔이요!} <커피 머신 스팀 소리> (경쾌한 어쿠스틱 기타) [오늘도 시작!]
```
