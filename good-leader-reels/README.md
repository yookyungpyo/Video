# 좋은 사람과 좋은 리더는 다르다 — good-leader-reels

2열 × 4행 스토리보드 한 장으로 만든 인스타그램 릴스입니다. "모두에게 좋은 사람으로 남으면서 좋은 리더가 될 수 있을까"라는 질문에서 시작해 "함께 일한다면, 해야 할 말은 해야 합니다"로 끝납니다.

- React + TypeScript + Remotion 4 · 1080×1920 · 30fps · H.264 + AAC
- **결과 파일:** `output/leadership_reels_final.mp4`
- **길이:** **57.37초(1721프레임)**. 목표는 40~45초였지만 실제 내레이션 길이를 우선했습니다. 아래 "길이"를 참고하세요.
- 내레이션 · 자막 · 배경음악이 모두 들어간 완성본입니다.

## 실행 (Windows · VS Code 터미널, `good-leader-reels` 폴더에서)

```bash
npm install                # 처음 한 번
npm run preview            # Remotion Studio 미리보기
npm run render             # → output/leadership_reels_final.mp4
npm run verify             # 1080×1920 · 30fps · 프레임 수 · 코덱 검사 + output/stills/scene-0X.png
```

이미지·음성·문구를 바꿀 때 쓰는 명령입니다.

```bash
npm run split              # assets/ 의 통합 스토리보드 PNG → scenes/scene_01~08.png (Node + sharp)
pip install numpy pillow   # 처음 한 번 (아래 두 명령의 Python 스크립트용)
npm run take               # assets/narration/full-take.mp3 → 장면별 scene-0X.wav (문장 사이 쉼 위치 기준)
npm run audio              # 장면 길이 · 자막 타이밍 · 음악 · 믹스 → src/data/timing.json, public/audio/track.mp4, subtitles.srt
```

## 이미지

- **분할:** `scripts/split-storyboard.mjs`(sharp)가 스토리보드(1024×1536)의 흰 구분선을 픽셀에서 찾아 2열 × 4행으로 자릅니다. 구분선이 남지 않게 안쪽 2px을 잘라내고, 왼쪽→오른쪽 · 위→아래 순서로 저장합니다. 장면마다 원본의 가로세로 비율이 조금씩 다르며(약 504×353 ~ 504×398) 그대로 유지합니다.
- **배치:** 장면이 가로형이라 세로 화면에 맞춰 자르거나 늘리지 않았습니다. 화면 폭 1080px에 **장면 전체**를 놓고, 위아래 남는 공간은 같은 장면을 확대해 흐리게 깐 배경으로 채웠습니다. 장면의 위아래 가장자리는 배경에 자연스럽게 녹아들게 했습니다. 얼굴이 잘리는 장면은 없습니다.
- **확대율:** 원본 대비 약 2.14배, 가장 당겼을 때(06, 스케일 1.21) 약 2.6배입니다. 인물 얼굴을 다시 생성하거나 변형하지 않았습니다.
- **고해상도 원본이 있다면:** `assets/scenes-hires/scene_0X.png`로 넣고 `npm run split` → `npm run render`.

## 장면별 연출 (`src/scenes/Scene01~08.tsx`)

화려한 모션은 넣지 않았습니다. 장면마다 카메라 움직임 하나, 전환은 부드러운 디졸브가 기본입니다. 장면 시간은 실제 음성에 맞춘 값입니다.

| # | 시간 | 카메라 | 효과 | 들어오는 전환 |
|---|---|---|---|---|
| 01 질문형 후킹 | 0.0–5.3 | 얼굴로 푸시인(1.00→1.16). 첫 프레임부터 움직이고 점점 느려져 질문이 끝나는 순간 멈춤 | 질문 뒤 0.6초 정지 | 검은 화면에서 페이드인 |
| 02 결론 | 5.3–12.1 | 느린 풀아웃(1.15→1.00) | 인물과 주변 사람들 사이의 거리가 드러남 | 디졸브 |
| 03 공감 | 12.1–17.5 | 표정으로 느린 푸시인(1.00→1.15) | 약한 비네팅이 조여옴 | 디졸브 |
| 04 문제 | 17.5–22.1 | 참석자들에서 리더 쪽으로 천천히 팬, 끝에 살짝 다가감(1.15→1.20) | 마지막에 리더 얼굴만 남기는 비네팅 | 디졸브 |
| 05 결과 | 22.1–27.9 | 느린 줌아웃(1.17→1.00) | 채도를 조금 낮춤 | 디졸브 |
| 06 심리적 반전 | 27.9–35.5 | 거울 속 인물로 천천히 푸시인(1.00→1.16), "미움받기 싫은"에서 0.5초 정지 후 아주 느리게 계속(→1.21) | 주변이 어두워지고 채도가 빠짐, 음악이 1/3 정도로 낮아짐 | 암전을 거쳐 등장 |
| 07 행동 | 35.5–45.6 | 얼굴과 손 사이로 부드러운 푸시인(1.00→1.13) | 따뜻한 조명 | 디졸브 |
| 08 엔딩 | 45.6–57.4 | 느린 푸시인(1.00→1.12) → "혼자 일하세요"에서 0.4초 정지 → 마지막 문장에서 천천히 풀아웃(→1.00) | 해 쪽에서 번지는 빛, 마지막 말 뒤 1.5초 여운 후 천천히 암전 | 긴 디졸브 |

- **가장 힘을 준 곳:** 06(유일한 암전 전환, 정지, 음악 감소)과 08(정지 후 풀아웃, 음악 고조)입니다.
- 이미지의 움직임(카메라)과 자막의 움직임은 서로 다른 레이어입니다.

## 내레이션

- **목소리:** ElevenLabs `eleven_v4` · **Minho - Deep & Trustworthy Narrator**(차분하고 낮은 톤의 성인 남성).
- **녹음:** 원고 전체를 한 번에 읽었습니다(54.8초, `assets/narration/full-take.mp3`). `npm run take`가 문장 사이 쉼 위치에서 장면별 `scene-0X.wav`로 나눕니다. **음성 속도를 바꾸거나 자르지 않았고, 대사를 줄이지 않았습니다.**
- **06의 속도:** TTS의 말 빠르기를 직접 지정할 수는 없어서, 원고에 쉼표를 넣어 호흡을 만들었습니다("…하지 않는 건, 배려가…", "그저, 내가…").
- **다른 테이크:** 같은 원고의 다른 테이크(55.5초)가 `assets/narration/take-b.mp3`에 있습니다. `full-take.mp3`로 복사한 뒤 `npm run take` → `npm run audio` → `npm run render`.
- **목소리 교체:** 새 녹음을 `full-take.mp3`로 넣고 같은 순서로 실행합니다. 장면별 파일(`scene-0X.wav`, mp3 · m4a 가능)을 직접 넣어도 됩니다.
- **음성 없이:** 장면별 음성 파일이 없으면 임시 타이밍으로 렌더링되고, 화면 왼쪽 위에 "임시 타이밍 · 음성 싱크 미완료"가 표시됩니다. 그 상태는 완성본이 아닙니다.

## 자막

- `src/components/Subtitle.tsx` — 이미지에 합성하지 않은 별도 레이어입니다.
- Pretendard, 흰색, 핵심 문구는 웜 골드(#D9B77A). 한 화면 최대 2줄.
- 등장은 부드러운 페이드와 12px의 미세한 상승뿐이고, 단어가 튀어 오르는 효과는 없습니다.
- **위치:** 장면 아래, 화면 중앙보다 아래쪽(y 약 1322–1584)입니다. 위 350px(인스타그램 "게시물" · 계정명), 아래 330px(캡션 · 버튼), 오른쪽 150px(버튼 열)에는 글자를 두지 않습니다.
- **동기화:** 구절마다 실제로 말하는 순간에 뜹니다.
- **문구 수정:** `src/data/script.json`(`{문구}` 강조, `\n` 줄바꿈) → `npm run audio` → `npm run render`. 자막 문구는 내레이션과 같습니다.

## 배경음악

- 사용 허가가 확인된 음원 파일이 없어서, 스크립트가 **직접 합성한 원곡**을 넣었습니다(샘플 · 외부 음원 없음).
- 미니멀 시네마틱 앰비언트, 60BPM, A단조: 낮은 펠트 피아노, 첼로 같은 저음 현, 거의 들리지 않는 낮은 펄스.
  - 01–05 절제된 진행 → **06에서 1/3 정도로 낮아짐**(현과 높은 피아노 한 음만) → 07은 C장조로 따뜻하게 → **08은 마지막 문장까지 서서히 고조**, 마지막 화음이 울리며 끝.
- 내레이션보다 낮게 깔고, 목소리가 나오는 동안은 자동으로 더 낮춥니다.
- **교체:** 사용 허가가 있는 음원을 `assets/music/music.mp3`(또는 wav, m4a)로 넣고 `npm run audio`.
- **음악 없이:** `src/data/script.json`의 `"music"`을 `"none"`으로 바꾸면 음악 없이 정상 렌더링됩니다.
- 효과음은 넣지 않았습니다.

## 길이

- 내레이션만 54.8초입니다. 원고가 약 270음절이라 차분한 속도로 읽으면 이 정도가 나옵니다.
- 여기에 장면마다 앞 0.3초 · 뒤 0.4초의 숨, 01 · 06의 정지 여백, 마지막 말 뒤 1.5초의 여운이 더해져 **57.4초**입니다. 목표 상한 45초보다 12.4초 깁니다.
- 장면별 계산: `output/timing-report.txt`
- 45초 안으로 줄이려면 대사를 줄여야 합니다. 07(10.1초)과 08(11.8초)이 가장 깁니다. 예: 07의 "불편하더라도 필요한 이야기는 해야 합니다."와 08의 첫 문장을 빼면 약 7초가 줄어듭니다.
