# 옳은 말을 하는 사람에서, 스스로 움직이게 만드는 사람으로 — leadership-choice-reels

4열 × 2행 코믹북 스토리보드 한 장으로 만든 인스타그램 릴스입니다. "내가 옳았는데 왜 아무도 움직이지 않았을까"에서 출발해 "스스로 선택하고 움직이게 만드는 리더"로 끝나는 1인칭 자기성찰 내레이션입니다.

- React + TypeScript + Remotion 4 · 1080×1920 · 30fps · H.264 + AAC
- **결과 파일:** `output/leadership_reels.mp4`
- **길이:** **46.27초(1388프레임)**. 목표는 45초였지만 실제 내레이션 길이를 기준으로 했습니다. 아래 "길이"를 참고하세요.
- 내레이션 · 자막 · 배경음악이 모두 들어간 완성본입니다.

## 실행 (Windows · VS Code 터미널, `leadership-choice-reels` 폴더에서)

```bash
npm install                # 처음 한 번
pip install numpy pillow   # 처음 한 번 (Python 스크립트용)
npm run preview            # Remotion Studio 미리보기
npm run render             # → output/leadership_reels.mp4
npm run verify             # 1080×1920 · 30fps · 프레임 수 · 코덱 검사 + output/stills/scene-0X.png
```

이미지·음성·문구를 바꿀 때 쓰는 명령입니다.

```bash
npm run split   # assets/ 의 통합 스토리보드 PNG → assets/scenes/scene01~08.png + public/scenes/ 작업 사본
npm run take    # assets/narration/full-take.mp3 → 장면별 scene-0X.wav (문장 사이 쉼 위치 기준)
npm run audio   # 장면 길이 · 자막 타이밍 · 음악 · 효과음 · 믹스 → src/data/timing.json, public/audio/track.mp4, subtitle.srt
```

## 이미지

- **찾기:** `scripts/split_storyboard.py`가 `assets/` 바로 아래 PNG 중 비율이 4:2 패널(2:1)에 가장 가까운 파일을 통합 스토리보드로 씁니다(현재 `assets/storyboard.png`, 1774×887).
- **분할:** 정확히 4열 × 2행으로 나눈 뒤, 칸마다 흰 여백과 검은 패널 테두리를 픽셀에서 찾아 잘라냅니다. 옆 칸의 선이 남지 않습니다. 왼쪽 위부터 오른쪽으로 `assets/scenes/scene01.png … scene08.png`(약 435×436, 원본 픽셀)로 저장합니다.
- **배치:** 칸 하나가 완성된 장면이라, 세로 화면에 맞춰 자르지 않고 **폭 900px 패널에 통째로** 놓았습니다. 얼굴이 잘리는 장면은 없습니다. 패널에는 코믹북처럼 흰 여백 · 검은 외곽선 · 딱딱한 그림자를 코드로 그렸고, 패널 뒤 페이지는 같은 장면을 흐리게 깐 배경 위에 하프톤과 장면별 그래픽을 올렸습니다.
- **확대율:** 원본 대비 약 2.07배, 가장 당겼을 때(01, 스케일 1.24) 약 2.6배입니다. 인물을 새로 그리거나 바꾸지 않았습니다.
- **고해상도 원본이 있다면:** `assets/scenes-hires/scene0X.png`로 넣고 `npm run split` → `npm run render`.

## 장면별 연출 (`src/scenes/Scene01~08.tsx`)

장면 시간은 실제 음성에 맞춘 값입니다.

| # | 시간 | 카메라 | 효과 | 들어오는 전환 |
|---|---|---|---|---|
| 01 후킹 · 질문 | 0.0–3.8 | 빠른 푸시인(1.00→1.13, 0.4초), 비트에서 한 번 더(→1.22) | 패널이 페이지에 내리꽂힘, 패널 둘레를 도는 속도선, "왜 아무도…"에 강한 비트(흔들림 · 플래시 · 튀어나오는 선) | — |
| 02 확신의 주장 | 3.8–8.8 | 느린 좌→우 팬(스케일 1.12 고정) | 페이지와 패널 두 모서리에 하프톤이 인쇄되듯 번짐 | 패널 슬라이드 ← |
| 03 하지만 결과는? | 8.8–12.8 | 느린 풀아웃(1.16→1.00) | 채도가 빠지고 페이지가 어두워짐, 음악이 1/3 정도로 물러남 | 패널 슬라이드 ↑ |
| 04 무엇이 문제였을까? | 12.8–19.2 | 슬로우 푸시인(1.00→1.15, 얼굴 쪽) | 화면 명암이 어두워지고 가장자리부터 그림자가 조여옴 | 어둠을 거쳐 전환 |
| 05 깨달음 | 19.2–24.9 | 인물 중심의 미세한 줌(1.03→1.10) | 04의 어둠에서 시작해 빛이 서서히 밝아짐, 전구에서 퍼지는 광선, 자막 순간 전구가 반짝 | 빛 플래시 |
| 06 답은 선택권 | 24.9–31.6 | 부드러운 팬(스케일 1.10 고정) | 패럴랙스: 페이지는 반대로, 패널 앞의 흐린 빛망울은 더 빠르게 이동 | 패널 슬라이드 → |
| 07 변화 | 31.6–37.6 | 풀아웃(1.17→1.00, 팀 전체로) | 밝고 따뜻한 색감으로 전환, 따뜻한 광선 | 스피드 라인 |
| 08 결론 · 메시지 | 37.6–46.3 | 슬로우 푸시인(1.00→1.11) 후 정지 | 해에서 번지는 부드러운 빛, 마지막 말 뒤 1.3초 여운 후 암전 | 디졸브 |

- **06의 패럴랙스에 대해:** 그림 한 장이라 인물과 배경을 따로 떼어 움직이지는 못했습니다. 대신 페이지(뒤) · 패널(가운데) · 빛망울(앞) 세 층이 서로 다른 속도로 움직입니다. 인물/배경 레이어 파일이 생기면 실제 인물-배경 패럴랙스로 바꿀 수 있습니다.
- **줌 한계:** 가장 큰 스케일이 1.24배(01)라 얼굴이 왜곡되거나 잘리지 않습니다.
- **전환 강도:** 감정에 맞춰 다릅니다. 01→02 · 06→07은 빠르고 세게, 03→04는 느리고 어둡게, 07→08은 부드럽게.

## 내레이션

- **목소리:** ElevenLabs `eleven_v4` · **Minho - Deep & Trustworthy Narrator**(차분한 중저음 남성).
- **녹음:** 대본 전체를 한 번에 읽었습니다(44.3초, `assets/narration/full-take.mp3`). `npm run take`가 문장 사이 쉼 위치에서 장면별 `scene-0X.wav`로 나눕니다. **음성 속도를 바꾸거나 자르지 않았습니다.**
- **다른 테이크:** 같은 대본의 다른 테이크(45.0초)가 `assets/narration/take-a.mp3`에 있습니다. `full-take.mp3`로 복사한 뒤 `npm run take` → `npm run audio` → `npm run render`로 바꿉니다.
- **목소리 교체:** 새 테이크를 `full-take.mp3`로 넣고 위와 같은 순서로 실행합니다. 장면별 파일(`scene-0X.wav`, mp3 · m4a 가능)을 직접 넣어도 됩니다.
- **음성 없이:** 장면별 음성 파일을 지우고 `npm run audio`를 실행하면 목표 시간(5 · 5 · 5 · 5 · 5 · 7 · 6 · 7초)으로 무음 프리뷰가 렌더링됩니다. 그 상태는 프리뷰이고 완성본이 아닙니다.
- 대본과 타임코드: `narration-script.txt`, `narration.srt`

## 자막

- `src/components/Subtitle.tsx` — 이미지에 합성하지 않은 별도 레이어입니다.
- Pretendard Bold, 흰색, 핵심 단어는 노란색, 반투명 검정 판.
- **동기화:** 장면마다 자막 하나가, 그 말이 실제로 나오는 순간에 뜹니다. 예: 03의 "사람들은 움직이지 않았다"는 내레이션이 그 문장을 말하기 시작하는 10.93초에 나옵니다.
- **안전 영역:** 위 350px(인스타그램 "게시물" · 계정명), 아래 330px(캡션 · 버튼), 오른쪽 150px(버튼 열)에는 글자를 두지 않습니다. 패널은 y 404–1312, 자막은 그 아래 1576까지입니다.
- **문구 수정:** `src/data/script.json`의 `subtitle.text`(`{단어}` 강조, `\n` 줄바꿈), `atChunk`는 몇 번째 내레이션 구절에 맞춰 띄울지입니다. 수정 후 `npm run audio` → `npm run render`.
- 플랫폼 자막용: `subtitle.srt`(화면 자막), `narration.srt`(내레이션 전체)

## 배경음악

- 사용 권한이 확인된 음원 파일이 없어서, 스크립트가 **직접 합성한 원곡**을 넣었습니다(샘플 · 외부 음원 없음, 76BPM).
  - 전반부(01–03) 절제된 긴장감: D단조, 낮게 눌린 베이스 펄스와 작은 틱, 어두운 패드. 03에서 1/3 정도로 물러납니다.
  - 중반부(04–05) 사색적: 느린 펠트 피아노 분산화음. 04는 낮게, 05는 한 옥타브 위로 올라가며 밝아집니다.
  - 후반부(06–08) 따뜻하고 희망적: F장조, 플럭 분산화음과 부드러운 킥, 장조 패드. 마지막 말 뒤 화음이 울리며 끝납니다.
- 내레이션보다 낮게 깔고, 목소리가 나오는 동안은 자동으로 더 낮춥니다.
- **교체:** 사용 권한이 있는 음원을 `assets/music/music.mp3`(또는 wav, m4a)로 넣고 `npm run audio`.
- **끄기:** `src/data/script.json`의 `"music"`을 `"none"`으로.
- **효과음(합성):** 01의 패널 착지와 강한 비트, 패널 슬라이드의 바람 소리, 04로 들어갈 때 낮은 울림, 05의 빛 차임, 08 끝의 차임.

## 길이

- 내레이션만 44.3초입니다. 장면마다 앞 0.25초 · 뒤 0.3초의 숨, 마지막 말 뒤 1.3초의 여운이 더해집니다.
- 음성이 목표보다 긴 장면(04 · 05 · 08)은 길어지고, 여유가 있던 장면(01 · 03)은 그만큼 줄였습니다. 그래도 **46.27초**로 목표보다 1.27초 깁니다.
- 장면별 계산: `output/timing-report.txt`
- 45초에 맞추려면 08의 여운을 줄이거나(`script.json`의 `tailHold`, 1.3 → 0.3이면 약 45.3초), 04의 문장을 줄여 다시 녹음합니다.
