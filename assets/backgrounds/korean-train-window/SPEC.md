# 달리는 전철 창밖 실사 배경 시리즈 (한국 전철)

인스타 릴스 레퍼런스(일본 통근열차 내부, 초록 모켓 벤치시트 + 창밖 풍경 변화 시리즈)를
**한국 전철(수도권 전철/코레일 구형 차량)** 버전으로 재현하는 연속 배경 세트.

## 컨셉

- **고정 요소 (모든 프레임 동일):** 빈 초록 모켓(직물) 벤치 시트, 스테인리스 수직 손잡이 봉,
  검은 고무 몰딩의 큰 창문, 시트백 상단의 따뜻한 형광등 라이트 스트립, 창문 위 한글 광고 플래카드.
  카메라는 통로 건너편에서 시트를 정면으로 바라보는 로우앵글. 인물 없음.
- **변화 요소 (프레임마다 창밖만 변경):** 달리는 열차의 연속된 여정을 표현.
- **그레이딩:** 어두운 틸-그린 시네마틱 톤, 필름 그레인, 노스탤직 무드.

## 프레임 시퀀스 (연속된 여정)

| # | 창밖 풍경 | 레퍼런스 대응 |
|---|-----------|--------------|
| 1 | 역 통과 — 스크린도어·기둥이 수평 모션블러로 흐르는 지하철 승강장 | IMG_4835 (블러 역사) |
| 2 | 저층 상가 거리 — 한글 간판, 전신주와 전선, 흐린 낮 | IMG_4836 (시가지) |
| 3 | 아파트 단지 — 동 번호가 칠해진 베이지색 고층 아파트 열, 봄 나무 | IMG_4837 (주거단지) |
| 4 | 한강 철교 통과 — 옅은 하늘, 강물 반짝임, 원경 스카이라인, 역광 | IMG_4838 (하늘/개방) |

## 규격

- **비율:** 1:1 (레퍼런스 릴 프레임 기준). 릴스 풀화면이 필요하면 생성 후 `outpaint`로 9:16 확장.
- **일관성 전략:** 동일 seed + 동일 인테리어 프롬프트 블록을 모든 프레임에 사용.
  edit 지원 프로바이더(예: nano-banana / FLUX Kontext 계열)가 있으면 1번 프레임을 base로
  `image_path` edit로 창밖만 교체하는 방식이 더 정확함 (`generate.py`가 자동 시도).
- **영상화(선택):** 각 스틸을 image-to-video(kling/seedance)로 5초 애니메이트 —
  "카메라 고정, 창밖 풍경만 수평으로 흐르고 손잡이 봉이 미세하게 흔들림" 프롬프트 사용.

## 실행 방법

```bash
# 이미지 생성 키 1개 필요 (아무거나 하나):
#   FAL_KEY (FLUX 계열 — 권장) / GOOGLE_API_KEY (Imagen) / OPENAI_API_KEY (DALL-E)
python assets/backgrounds/korean-train-window/generate.py
```

출력: `projects/korean-train-window-bg/assets/images/frame_01.png` ~ `frame_04.png`

프롬프트 원본은 [`prompts.json`](prompts.json) 참고.
