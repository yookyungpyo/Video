# AI에게 내 직업의 유통기한을 물었다 — ai-job-expiration

사용자와 AI가 실시간으로 대화하는 채팅 화면 한 장으로 진행되는 인스타그램 릴스입니다.
직업을 하나씩 물을 때마다 AI의 답이 조금씩 차가워지고, "퍼블리셔"에서는 음악이 끊긴 채 AI가 **"이건… 대답 안 하면 안 될까?"** 하고 답을 피합니다. AI 시대의 직업 변화를 소재로 한 풍자입니다.

- React + TypeScript + Remotion 4 · FFmpeg · 1080×1920 · 30fps · H.264(yuv420p, BT.709) + AAC · MP4 faststart
- **결과 파일:** `ai_job_expiration_final.mp4`
- **길이:** **62.97초(1889프레임)** — 목표 60~75초 안
- 내레이션 없음. 타이핑 · 전송 · 응답 효과음과 배경음악만 있습니다.

## 실행 · 렌더링 명령어 (`ai-job-expiration` 폴더에서)

```bash
npm install                # 처음 한 번
npm run preview            # Remotion Studio 미리보기 (컴포지션: AiJobExpiration)
npm run render             # → ai_job_expiration_final.mp4
npm run verify             # 해상도 · fps · 프레임 수 · 코덱 · yuv420p · faststart · 오디오 검사 + output/stills/
```

대사나 타이밍을 바꿀 때:

```bash
# src/config/chat.json 수정 후
npm run timeline           # 대사 · 속도 · 정적 → 프레임 단위 타임라인 (src/data/timeline.json)
pip install numpy          # 처음 한 번
npm run audio              # 같은 타임라인 위에 효과음 · 음악 배치 → public/audio/track.mp4
npm run render
```

## 구성

채팅 화면은 첨부 이미지를 잘라 쓴 것이 아니라 **React와 CSS로 다시 만든 것**이고, 모든 글자는 프레임마다 동적으로 출력됩니다. 첨부 이미지는 `reference/chat-reference.png`에 디자인 참고용으로만 들어 있습니다.

| 컴포넌트 (`src/components/`) | 역할 |
|---|---|
| `ChatHeader` | 상단 헤더: 메뉴 · "AI CHAT" · 더보기 |
| `ChatMessage` | 말풍선 한 줄: 사용자(오른쪽, 흰 실루엣) / AI(왼쪽, 보라색 네온 아이콘 — 생각하고 답하는 동안 빛남) |
| `UserTyping` | 입력창 안에서 한 글자씩 타이핑되는 글자와 커서 |
| `AIStreaming` | AI 답변의 스트리밍 출력(단어 · 짧은 조각 단위)과 답변 중 커서 |
| `ThinkingIndicator` | 점 세 개가 차례로 켜지는 생각 중 표시 ("생각 중" 라벨 포함) |
| `AutoScroll` | 메시지 영역과 자동 스크롤. 아직 보내지 않은 메시지는 아예 배치하지 않음 |
| `ChatInput` | 하단 고정 입력창, 여러 줄이면 위로 늘어남, 전송 버튼 활성화 · 클릭 모션 |
| `CameraZoom` | 핵심 답변에서만 105~110% 확대, 다음 질문을 입력하면 복귀 |
| `SoundController` | 사운드 트랙 |
| `EndingScreen` | 암전 후 엔딩 문장 타이핑 |
| `layout.ts` · `Icons.tsx` | 말풍선 위치 · 스크롤 계산 / 아이콘 |

- **타이밍 설정 파일:** `src/config/chat.json` — 메시지별 출력 속도(`perChar`), 문장 앞 정적(`before`), 생각 시간(`think`), 읽는 시간(`hold`), 확대, 효과음, 음악 전환이 모두 여기 있습니다. 단위는 프레임(30 = 1초)입니다.
- **프레임 기반:** `scripts/build-timeline.mjs`가 설정을 글자 하나하나의 프레임 번호로 바꿔 `src/data/timeline.json`에 저장합니다. 화면과 사운드가 같은 파일을 읽으므로 렌더링할 때마다 타이밍이 똑같이 재현됩니다. 타이핑의 불규칙한 속도도 고정된 시드에서 나옵니다.
- **한글:** 글자 단위(`Intl.Segmenter`)로 출력해서 자모가 분리되거나 깨지지 않습니다. 이모지도 한 글자로 처리합니다.

## 장면별 타이밍

| 장면 | 시간(초) | 내용 |
|---|---|---|
| 01 대화 시작 | 0.0–8.2 | 빈 화면(헤더 + 입력창) → 세 줄 질문 타이핑 → 전송 → "좋아. 상처받지 않기다." → 1초 유지 |
| 02 프론트엔드 개발자 | 8.2–15.4 | 첫 문장 빠르게 → 0.8초 정지 → 둘째 문장 천천히. "책임져야 하잖아"에서 105% 확대 + 저음 |
| 03 UI/UX 디자이너 | 15.4–21.9 | 전송 직후 바로 답변. 첫 문장 매우 빠르게, 둘째 문장 여유 있게 → 1.5초 유지 |
| 04 UI 기획자 | 21.9–29.2 | "음…" → 1초 정지 → 나머지. "아직 화면설계서 그리고 있어?"에서 110%까지 천천히 확대, 심장박동 |
| 05 퍼블리셔 | 29.2–38.7 | **전송 순간 음악 정지** → "생각 중" 2초(점 순차 점멸) → "잠깐만." → 1.2초 완전 정지 → "이건…" → "대답 안 하면 안 될까?" 한 글자씩(흰색, 조금 크고 굵게), 105% 확대 → 2초 유지 |
| 06 마지막 질문 | 38.7–48.1 | 느린 타이핑 → "글쎄…" → 1초 정지 → 담담한 답변. 완성되는 순간 음악 제거 |
| 07 침묵 | 48.1–54.5 | 점을 하나씩 입력 → 전송 → AI 무응답, 입력창 커서만 깜빡임 2초 → 암전 |
| 08 엔딩 | 54.5–63.0 | "당신의 직업은 살아남을 것인가."(흰색) → 1.5초 → "당신은 살아남을 것인가."(붉은색) + 묵직한 베이스 → 3초 유지 |

## 화면 디자인

- 블랙 · 다크 그레이 배경에 보라색 안개, 다크 그레이 둥근 말풍선(AI 말풍선에는 꼬리), 흰 글자, Pretendard. 붉은 네온은 엔딩의 마지막 문장에만 씁니다.
- AI 아이콘은 직접 그린 네 꼭지 별 모양이고 특정 서비스의 로고가 아닙니다.
- 글자는 첨부 이미지보다 크게(말풍선 46px, 강조 문장 54px) 잡았고, 한 화면에 최근 질문과 답변 2세트 정도가 보입니다.
- 이모지는 첨부 이미지에 있던 것만 문장 끝에 하나씩 썼습니다. 렌더링하는 컴퓨터의 이모지 폰트로 그려지므로 Windows에서 다시 렌더링하면 이모지 모양이 조금 다릅니다.
- **안전 영역:** 채팅 앱 전체를 y 356–1590 사이의 창 안에 넣었습니다. 위 350px · 아래 330px(인스타그램 UI 영역)에는 배경만 있고, 글자는 오른쪽 150px 안으로 들어가지 않습니다. 확대할 때도 글자가 그 영역으로 밀려나지 않도록 확대 기준점을 오른쪽에 두었습니다(그래서 확대 중에는 왼쪽의 AI 아이콘이 조금 잘립니다).

## 사운드 (`scripts/build_audio.py`)

모두 스크립트가 직접 합성한 소리입니다(샘플 · 외부 음원 없음).

- **효과음:** 글자마다 키보드 소리(스페이스 · 줄바꿈은 다른 소리), 전송음, AI 답변 시작 차임과 스트리밍 틱, 생각 중 전자음, 02의 저음, 엔딩 베이스.
- **음악:** 01–02 가벼운 전자음 루프(104BPM) → 03–04 낮은 베이스 펄스와 서서히 커지는 긴장음, 04부터 점점 빨라지는 심장박동 → **05 완전한 정적(타이핑 소리만)** → 06 낮고 얇은 음 → 마지막 답변이 완성되면 제거 → 07 키 소리만 → 08 묵직한 베이스와 긴 여운.
- 웃음소리나 과장된 코미디 효과음은 없습니다.

## 검수

`npm run verify`와 MP4에서 뽑은 프레임으로 확인한 항목입니다.

- 1080×1920 · 30fps · 1889프레임 · 62.97초 · H.264 · yuv420p · AAC 48kHz 스테레오 · faststart
- 아직 진행되지 않은 질문 · 답변이 미리 보이지 않는지, 한글이 깨지지 않는지, 스크롤과 확대, 안전 영역
- 퍼블리셔 구간의 정적(음악이 실제로 0이 되는지)

직접 확인이 필요한 항목입니다.

- **소리:** 음량과 타이밍은 수치로 확인했고, 음색과 분위기는 들어 보고 판단해야 합니다.
- **아이폰 · 인스타그램:** 호환되는 형식으로 인코딩했지만, 실제 저장과 업로드는 기기에서 확인해야 합니다.

## 수정 이력

- **퍼블리셔 답변 완화:** 처음 버전의 "잠깐만. / 아직도 남아 있어?"(붉은 네온, 115% 확대)가 너무 세다는 의견에 따라 "잠깐만. / 이건… / 대답 안 하면 안 될까?"로 바꿨습니다. 음악 정지와 느린 출력(침묵의 타이밍)은 그대로 두고, 글자는 흰색, 확대는 105%로 줄였습니다. 예전 연출로 되돌리려면 `src/config/chat.json`의 `a5`에서 문구와 `"tone": "red"`, `"scale": 1.15`를 바꾸면 됩니다.
