# AI 시대, 우리 회사에 꼭 있는 9가지 직장인 유형 — ai-office-types

3×3 클레이 스토리보드 한 장으로 만든 인스타그램 릴스용 직장인 블랙코미디입니다. 유형마다 짧은 대화가 오가고, 끝에 한 줄 자막(펀치라인)이 붙습니다.

- React + TypeScript + Remotion 4 · 1080×1920 · 30fps · H.264 + AAC
- **결과 파일:** `output/ai-office-types.mp4`
- **길이:** **87.47초(2624프레임)**. 목표는 65~75초였지만, 실제 대사 길이와 코미디 호흡을 기준으로 했습니다. 아래 "길이"를 참고하세요.

## 실행 (Windows · VS Code 터미널, `ai-office-types` 폴더에서)

```bash
npm install                # 처음 한 번
npm run preview            # Remotion Studio 미리보기
npm run render             # → output/ai-office-types.mp4
npm run verify             # 1080×1920 · 30fps · 프레임 수 · 코덱 검사 + output/stills/scene-0X.png
```

이미지·대사·음성을 바꿀 때 쓰는 명령입니다.

```bash
npm run split              # assets/storyboard.png → public/scenes/scene-01~09.png (Node + sharp)
pip install numpy pillow   # 처음 한 번 (오디오 스크립트용 Python 패키지)
npm run audio              # 대사 분리 · 장면 길이 계산 · 재즈 배경음악 · 믹스 → src/data/timing.json, public/audio/track.mp4
```

## 구성

| 구간 | 내용 |
|---|---|
| OPENING (3초) | 검은 배경에 타이틀이 단어별로 등장하고, 마지막 0.9초에 9장면이 플래시처럼 지나감 |
| 01 라떼는 부장형 | 부장 얼굴로 천천히 줌인 → 두 번째 대사에서 직원 쪽으로 이동 → 0.3초 정적 뒤 자막 |
| 02 일복 터진 에이스형 | 노트북 쪽으로 빠른 줌인 → "이것도, 이것도, 이것까지"에 맞춰 업무 칩이 쌓임 → 자막에서 화면이 살짝 흔들림 |
| 03 조용한 칼퇴 고수형 | 여유로운 얼굴에서 시작해 천천히 줌아웃, "18:00 퇴근" 칩, 자막에 능청스러운 두 음 |
| 04 생각도 외주 준 대리형 | 질문 뒤 정적 → "잠시만요." → 머리 둘레 로딩 링과 순서대로 켜지는 점 3개 |
| 05 자신감만 만렙 과장형 | 자신 있게 줌인하며 "확신 100%" 게이지 → "근거는?"에서 음악과 카메라가 멈추고 "근거 0%" → 마지막 대사는 작은 회색 자막 |
| 06 구독료 부자형 | AI 도구 타일 12개가 빠르게 등장(결제음) → 마지막 대사 뒤 모든 움직임과 음악이 멈춤 |
| 07 몰래 성장하는 실속형 | 영상에서 가장 차분한 줌인 하나, "AI 초안 → 내 수정 → 완성 ✓" 막대가 단계별로 길어짐 |
| 08 AI 부하직원 둔 팀장형 | 팀장 → "아니, AI한테."에서 로봇 쪽으로 이동 → 로봇 둘레 진행 링과 작업 목록 |
| 09 입만 AI 전문가형 | 말할수록 서서히 줌인 → 마지막 대사 뒤 정적, 화면이 넓어지며 직원들 얼굴만 밝게 남김 → 자막 |
| ENDING (4.8초) | 9가지 유형 3×3 그리드 + "당신은 어떤 유형인가요?" → "아니면… 지금 누군가 떠오르셨나요?" (2.6초 유지 후 종료) |

대사와 정확한 타임코드는 [`SCRIPT.md`](SCRIPT.md)에 있습니다.

## 이미지

- **분할:** `scripts/split-storyboard.mjs`가 스토리보드 크기(2048×2048)를 읽고, 흰 구분선을 픽셀에서 찾아 3×3 칸 좌표를 계산합니다.
  - 각 칸의 4px 안쪽을 잘라 `public/scenes/scene-01.png … scene-09.png`(약 670×670)로 저장합니다. 원본 픽셀 그대로이고, 다시 그리거나 다른 이미지로 바꾸지 않았습니다.
  - 순서는 왼쪽 위 → 오른쪽 아래입니다.
- **배치:** 칸이 정사각형이라 세로로 늘리지 않고 화면 가운데 **920×920 카드**에 통째로 놓았습니다. 나머지는 같은 이미지를 흐리게 깐 배경입니다.
  - 카메라는 카드 안에서 움직입니다(줌 1.0~1.42배). 얼굴과 주요 소품이 잘리지 않게 장면별로 맞췄습니다.
  - 흐린 배경이 카메라와 반대로 움직여 깊이감을 줍니다(레이어 패럴랙스). 인물의 입이나 팔은 변형하지 않았습니다.

## 자막

- **폰트:** Pretendard. 영상에 직접 렌더링합니다.
- **안전 영역:** 위 350px(인스타그램 게시물 화면의 "게시물"·계정명 영역)과 아래 330px에는 글자와 그래픽을 두지 않습니다. 제목은 y 356부터, 카드는 y 490–1410, 자막은 그 아래 1590까지입니다.
- **대사 자막:** 화면 아래 안전 영역에 최대 2줄, 반투명 검정 박스. 위에 화자 탭이 붙습니다(주인공은 노랑, 다른 사람은 회색).
- **강조:** 핵심 단어만 노란색 굵은 글씨로, 등장할 때 아주 살짝 커집니다.
- **펀치라인 자막:** 더 크고 굵게, 위에 노란 선. 스프링으로 등장합니다.
- **유형 제목:** 카드 위에 `TYPE 03 / 09`와 유형 이름.
- **문구 수정:** `src/data/script.json` (`\n` 줄바꿈, `{단어}` 강조).

## 음성 · 음악

- **목소리 3개 (ElevenLabs `eleven_v4`)** — 역할마다 다른 목소리입니다.
  - 주인공(직원·대리·과장·팀장): **Leo** — 담담하고 현실적인 말투
  - 부장·상사·대표: **Hyeonwoo** — 50대의 점잖고 권위 있는 말투
  - 동료·팀원: **Rowan** — 평범한 말투
- **녹음 방식:** 목소리별로 그 사람의 대사를 순서대로 한 번에 읽었습니다(`assets/narration/take-*.mp3`). `npm run audio`가 쉼 위치에서 대사별로 잘라 `assets/narration/lines/sNN-lM.wav`로 저장하고, 장면 타임라인에 배치합니다.
  - 음성 속도는 바꾸지 않았습니다.
  - 상사 테이크는 자동 분리가 한 군데 틀려서("오, 그래?"가 앞 대사에 붙음) `script.json`의 `voices.boss.boundaries`로 경계를 지정했습니다.
- **대사 하나만 교체:** `assets/narration/lines/s05-l3.mp3`처럼 같은 이름의 mp3나 m4a를 넣고 `npm run audio` → `npm run render`를 실행합니다.
- **코미디 정적:** 01 자막 전 0.3초, 04 질문 뒤, 05 "근거는?", 06 마지막, 09 마지막 대사 뒤에 음악이 잠깐 멈춥니다.
- **배경음악:** 사용 권한이 확인된 음원 파일이 없어서, 스크립트가 **직접 합성한 원곡**을 넣었습니다(샘플·외부 음원 없음).
  - 116BPM 스윙. 워킹 베이스, 브러시 드럼, 띄엄띄엄 치는 피아노입니다. 대사 구간에서는 자동으로 낮아집니다.
  - **교체:** 음원을 `assets/music/music.mp3`(또는 wav, m4a)로 넣고 `npm run audio`를 실행합니다.
  - **비우기:** `src/data/script.json`의 `"music"`을 `"none"`으로 바꿉니다.
  - 확인용 분리 파일: `public/audio/voice.mp4`(음성만), `public/audio/music.mp4`(음악만)
- **효과음:** 작고 건조한 소리만 넣었습니다(예능식 효과음 없음). 오프닝 플래시 틱, 업무 칩 팝, 능청스러운 두 음, 생각 점, 결제 벨, 개선 차임, 로봇 작업음.

## 길이

- **대사만 45초**입니다(주인공 19초, 상사·대표 22초, 동료 4초).
- 여기에 오프닝 3초, 엔딩 4.8초, 대사 사이 호흡과 정적, 펀치라인 자막을 읽을 시간(자막당 1.5~3.3초)이 더해져 **87.5초**가 됩니다. 목표 상한 75초보다 12.5초 깁니다.
- 음성을 빠르게 하거나 자르지 않았습니다. 장면별 길이는 `output/timing-report.txt`에 있습니다.
- **75초 안으로 줄이려면** 다음 중에서 고르면 됩니다.
  - 09의 대표 대사 3개 중 1개 빼기 (약 -4초)
  - 펀치라인 자막 유지 시간 줄이기 (`scripts/build_audio.py`의 `hold`, 약 -3초)
  - 유형 하나 빼기
