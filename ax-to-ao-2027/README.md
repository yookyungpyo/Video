# 2027년, AX에서 AO로 — ax-to-ao-2027

> 당신의 조직은 AI를 활용하는 조직인가? 아니면 AI로 움직이는 조직인가?

8컷 클레이 스토리보드 한 장으로 만든 인스타그램 릴스입니다. AI를 **쓰는** 조직(AX)에서 AI Agent가 **일하는** 조직(AO · Agent Organization)으로 넘어가는 흐름을 Agent 워크플로 모션그래픽으로 보여줍니다.

- React + TypeScript + Remotion 4 · 1080×1920 · 30fps · H.264 + AAC
- **결과 파일:** `output/ax-to-ao-2027.mp4`
- **길이:** **56.87초(1706프레임)**. 목표는 약 50초(허용 48~55초)였지만, 실제 내레이션 길이를 기준으로 했습니다. 아래 "길이"를 참고하세요.

## 실행 (Windows · VS Code 터미널, `ax-to-ao-2027` 폴더에서)

```bash
npm install                # 처음 한 번
pip install numpy pillow   # 처음 한 번 (Python 스크립트용)
npm run preview            # Remotion Studio 미리보기
npm run render             # → output/ax-to-ao-2027.mp4
npm run verify             # 1080×1920 · 30fps · 프레임 수 · 코덱 검사 + output/stills/scene-0X.png
```

이미지·음성·문구를 바꿀 때 쓰는 명령입니다.

```bash
npm run split   # assets/storyboard.png → storyboard/scene-01~08.png (원본 픽셀) + public/scenes/ 작업 사본
npm run take    # assets/narration/full-take.mp3 → 장면별 scene-0X.wav (문장 사이 쉼 위치 기준)
npm run audio   # 장면 길이 · 자막 타이밍 · 음악 · 효과음 · 믹스 → src/data/timing.json, public/audio/track.mp4, subtitle.srt, narration-script.txt
```

## 장면별 연출 (`src/scenes/Scene01~08.tsx`)

장면마다 카메라와 모션그래픽을 다르게 썼습니다. 모든 장면은 흐린 배경(원경) · 장면 카드(중경) · 모션그래픽(근경) 세 층으로 나뉘고, 카메라가 움직이면 층마다 다른 속도로 움직입니다(패럴랙스).

### 핵심 장면 (06)

고객 요청 하나가 Agent 세 명을 거쳐 제안서가 되는 과정을 한 화면에서 보여줍니다.

1. "고객 요청" 카드가 내려와 분석 Agent에게 들어감
2. Agent마다 일하는 동안 진행 링이 차오르고, 끝나면 초록 체크
3. 끝난 Agent가 다음 Agent에게 데이터 패킷을 넘김 (분석 → 제안 → 일정)
4. 각 Agent의 결과가 아래 제안서로 흘러 내려가 쌓임 (1/3 → 2/3 → 3/3)
5. "제안서 완성 ✓" 도장

화면 위의 `요청 › 분석 › 초안 › 일정` 표시가 현재 단계를 알려줍니다.

## 이미지

- **분할:** `scripts/split_storyboard.py`가 스토리보드(1672×941)의 흰 구분선을 픽셀에서 찾아 2×4 칸으로 자릅니다. 구분선이 섞이지 않게 안쪽 3px을 잘라 `storyboard/scene-01.png … scene-08.png`로 저장합니다. 원본 픽셀 그대로이고 인물을 다시 그리지 않았습니다.
- **배치:** 칸이 거의 정사각형(약 410×465)이라 세로로 늘리지 않고, 화면 가운데 **폭 800px 카드에 장면을 통째로** 놓았습니다. 나머지는 같은 장면을 흐리게 깐 배경입니다. 얼굴이 잘리는 장면은 없습니다.
- **해상도 한계:** 한 칸이 약 410px이라 화면에서 약 2배(푸시인 때 최대 2.6배) 확대됩니다. Lanczos로 키우고 약하게 선명도를 올렸지만, 가까이 들어간 구간은 조금 부드럽게 보입니다.
- **고해상도 원본이 있다면:** 장면별 이미지를 `storyboard-hires/scene-0X.png`로 넣고 `npm run split` → `npm run render`를 실행하면 그 이미지를 씁니다.

## 자막

- **폰트:** Pretendard(흰색), 핵심 단어는 아이스블루. 영상에 직접 렌더링합니다.
- **안전 영역:** 위 350px(인스타그램 게시물 화면의 "게시물"·계정명 영역), 아래 330px, 오른쪽 150px에는 글자를 두지 않습니다. 타이틀은 y 356부터, 카드는 y 502–1406, 자막은 그 아래 1590까지입니다.
- **장면 02~07:** 화면 아래에 문장 단위 자막(1~2줄, 어두운 그라데이션 판).
- **장면 01 · 08:** 문구 자체가 키네틱 타이포라서 일반 자막을 따로 넣지 않았습니다(같은 글자 중복 방지).
- **플랫폼 자막용:** `subtitle.srt` (전체 문장, 실제 음성 타이밍)
- **문구 수정:** `src/data/script.json` (`{단어}` 강조, `\n` 줄바꿈) → `npm run audio` → `npm run render`

## 음성 · 음악

- **내레이션:** ElevenLabs `eleven_v4` · **Ji-hwan (Cinematic Deep Baritone)** — 중저음 남성.
  - 대본 전체를 한 번에 읽었습니다(54.1초, `assets/narration/full-take.mp3`). 문장 사이 쉼 위치에서 장면별 `scene-0X.wav`로 나눴습니다.
  - 음성 속도를 바꾸거나 자르지 않았습니다. 장면 길이와 자막·모션그래픽 타이밍이 실제 음성을 따라갑니다.
  - 대본과 타임코드: `narration-script.txt`
- **목소리 교체:** `assets/narration/full-take.mp3`를 바꾸고 `npm run take` → `npm run audio` → `npm run render`. 장면별 파일(`scene-0X.wav`, mp3·m4a 가능)을 직접 넣어도 됩니다.
- **음성 없이:** `assets/narration/`의 장면 파일을 지우고 `npm run audio`를 실행하면 대본 길이로 계산한 타이밍으로 무음 미리보기가 렌더링됩니다.
- **배경음악:** 사용 권한이 확인된 음원 파일이 없어서, 스크립트가 **직접 합성한 미니멀 일렉트로닉 원곡**을 넣었습니다(샘플·외부 음원 없음).
  - 112BPM. 01은 외치는 단어마다 임팩트, 03은 킥 없이 긴장, 04에서 드롭, 05–06은 풀 그루브, 07은 하프타임, 08은 패드만 남고 마지막 말 직후 끝납니다. 목소리가 나올 때는 자동으로 낮아집니다.
  - **교체:** 음원을 `assets/music/music.mp3`(또는 wav, m4a)로 넣고 `npm run audio`를 실행합니다.
  - **끄기:** `src/data/script.json`의 `"music"`을 `"none"`으로 바꿉니다.
- **효과음:** 임팩트(01), 라이저·우시(전환), 연결선이 켜질 때의 짧은 블립(04–06), 완료 차임(06–07). 모두 합성음입니다.

## 길이

- **내레이션만 54.1초**입니다. 요청하신 대본을 자신감 있는 속도로 읽은 실제 길이입니다.
- 여기에 장면 사이 호흡, 06의 제안서 완성 여백(1.1초), 마지막 질문 뒤 유지와 암전(2.3초)이 더해져 **56.9초**가 됩니다. 허용 범위 상한 55초보다 1.9초 깁니다.
- 장면별 계산: `output/timing-report.txt` (`npm run audio`가 만듭니다)
- **55초 안으로 줄이려면** 둘 중 하나입니다.
  - 05의 문장을 줄인 대본으로 다시 녹음 (05가 9초로 가장 깁니다. 예: "AI Agent가 계획하고, 실행하고, 협업하는 조직입니다.")
  - 조금 더 빠른 목소리로 다시 녹음
